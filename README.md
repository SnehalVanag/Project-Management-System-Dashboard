# 📊 Project Management Dashboard – Construction Tracking

## 🔍 Overview
This dashboard is built to track and analyze construction project progress.  
It compares **planned vs actual timelines**, highlights **delays**, and provides a **Gantt chart view** for better decision-making.

## ✨ Features

- 📅 **Project Timeline Overview**
  - Total project duration
  - Planned vs Actual dates

- 📊 **Task-Level Breakdown**
  - Activity-wise tracking
  - Start & Finish comparison
  - Duration calculation

- ⏱ **Delay Analysis**
  - Automatic delay calculation
  - Highlights delayed activities

- 📈 **Gantt Chart Visualization**
  - Visual timeline of tasks
  - Easy identification of overlaps & delays

- 📌 **Performance Summary**
  - Finished Early
  - Finished On Time
  - Finished Late

---

## 🎯 Purpose

- Track construction project execution  
- Identify delays and inefficiencies  
- Improve planning accuracy  
- Provide data-driven insights
